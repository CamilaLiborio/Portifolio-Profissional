Sistema de uma lanchonete

O Sistema de uma Lanchonete é um projeto acadêmico que desenvolvi em Python para mostrar minha capacidade de criar soluções de gestão de dados. Ele se concentra em duas funções essenciais: o cadastro completo de produtos e o processamento rápido de pedidos, incluindo o cálculo automático dos valores. Ao criar este sistema, apliquei a lógica de programação de forma prática e organizada, resultando em um código que é eficiente e fácil de entender.

Calculadora-IMC

Como meu primeiro projeto em desenvolvimento web, esta calculadora de IMC foi fundamental para iniciar minha jornada com HTML, CSS e JavaScript. Através dela, pude ter minha primeira experiência prática com a lógica de programação e a criação de interfaces, aprendendo a estruturar, estilizar e dar funcionalidade a uma aplicação. O projeto, que calcula e classifica o IMC com base nos padrões da Organização Mundial de Saúde (OMS), solidificou minha base para futuros aprendizados.

Site de receitas

Este projeto foi desenvolvido em sala de aula, com o objetivo principal que era aplicar as habilidades de HTML e CSS para criar um site funcional e com uma interface intuitiva, capaz de se adaptar a diferentes tamanhos de tela. Utilizei HTML para estruturar todo o conteúdo e CSS para estilizar a página. Este projeto reforça meu entendimento sobre como o HTML e o CSS trabalham juntos para construir a parte visual de um site.
